        Six decisions that carry the score

        Each one is measured, not asserted — the deltas below come from artifacts/ablate.json, the same file the table above reads.

        Questions are chosen, not listed

        The customer discloses undisclosed constraints whose type matches the attribute named. So a question's value is exactly how finely it splits the live candidates — computable, and computed: IG(a) = H(C) − E[H(C | reply)]. Removing this costs 0.379 of composite score, more than everything else combined.

        Show one product, not ten

        A session ends the instant the target appears anywhere in the list. So padding a low-confidence turn buys a badly-ranked hit that ends the session before a better turn arrives. While the field is wide the agent offers the one product it believes. MRR climbs 0.690 → 0.968 for 0.65 of a turn.

        A miss is evidence

        If a turn showed ten products and the session continued, the target was not among them. That is not a heuristic — it follows from how a turn is scored — and it removes candidates for free. It is withheld in intent override sessions until the override lands, where it would be unsound.

        Override re-weights, it does not erase

        The brief asks for slot erasure on intent override. Measured against the actual customer, the abandoned preference is still a true attribute of the target, so erasing costs 0.009. The agent demotes instead. This is the one place it deliberately departs from the brief, and the ablation is the argument.

        Rarity decides what a phrase may do

        A disclosed constraint may nominate candidates only if at most 500 products carry it. The largest category holds 1,354, so a phrase less selective than a whole category cannot narrow anything — letting “Buckle closure” nominate replaced a 258-product shelf with an 18,000-product haystack. It still scores what other routes find. Same score, evaluation 5× faster.

        A turn is never empty

        An unreadable message leaves nothing to rank, and a turn that returns nothing cannot hit while still spending itself. Never happens on the public set; the organizer reserves the right to reword the customer, so the agent falls back to the held category ranked by quality. It costs nothing an empty list does not already cost — the public score is identical to five decimals, because the path never runs there.
